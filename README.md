# Daily English Learning Portal

A static English-learning portal for banking, SSC and other competitive-exam preparation.

## Deployment
- Publish directory: repository root
- Build command: none
- Homepage: index.html
- Annotated lesson: lessons/2026-11-06-annotated.html
- Daily editorial (12 November 2026): lessons/2026-11-12-editorial.html

The homepage includes a link to the 6 November annotated lesson. New daily lessons can be added as separate pages or imported through the portal's lesson manager.

## Progress and browser storage
Learning progress is stored in the browser using localStorage. It is not automatically synchronized between browsers or devices. Export a backup from the portal before clearing browser data.
